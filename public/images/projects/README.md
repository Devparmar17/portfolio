# Project covers

Drop project screenshots or case-study covers here, then point at them from
`data/portfolio.js`:

```js
image: "/images/projects/apna-pg.png",
```

A card with no `image` falls back to a styled blueprint plate with the
project glyph, so leaving this empty is a valid choice — nothing breaks.

**Recommended:** 1200 × 675 (16:9), PNG or JPG. `next/image` handles the
resizing and modern formats from there.
